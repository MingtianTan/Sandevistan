# SPINE / Sandevistan

A research vision, written as a web page: a small, embodiment-agnostic **reflex layer** that lives between a
vision-language-action model and a robot's actuators, reacts in milliseconds on proprioception and fast visual cues,
slows the plan's clock when it must ("bullet time") and overrides it when it has to. Nothing here is built; the page
exists to think the idea through and to show it to people who might want to supervise it as a PhD.

Live page: <https://mingtiantan.github.io/Sandevistan/> (GitHub Pages; the page is public, the repository is private).

- `index.html`, `styles.css`, `main.js`: the page (open `index.html` locally, or serve the folder).
- `assets/figures/`: the three drawn figures (`make_figures.py` → SVG → PNG via headless Chrome).
- `assets/media/`: reflex diagrams from Wikimedia Commons; licences and authors in `CREDITS.md`.

Companion project with the data pipeline the plan relies on: [aerial manipulation](https://mingtiantan.github.io/aerial-manipulation/).

"Sandevistan" is the name of a reflex-booster implant in Cyberpunk 2077 (CD Projekt Red), used here as a nickname.
